# Tactical Pressing Visualizer

A lightweight, high-performance 2D HTML5 Canvas web app designed for soccer coaches to visualize, analyze, and demonstrate attacking build-ups and defensive pressing triggers in real time.

## Features
- **Dual-Layer Canvas Engine:** Optimized for fluid performance on low-spec laptops.
- **Dynamic Cover Shadows:** Automatically computes blocked passing lanes behind pressing attackers.
- **Interactive Drag-and-Drop:** Reposition players and ball on the fly with instant spatial recalculations.
- **Zero-Dependency Architecture:** Runs directly in any modern browser without heavy node modules or build steps.

## Quick Start
1. Clone the repository or download the source files.
2. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).
